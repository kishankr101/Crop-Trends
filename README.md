# 🌾 AI‑Based Crop Production Trend Predictor

Agriculture lacks predictive decision‑support systems that help farmers and planners
anticipate crop surplus and shortages before they occur.

## 🔍 What this app does
- Analyzes historical crop production data
- Predicts future production trends using ML
- Flags potential surplus or shortage risks
- Provides actionable recommendations

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit‑learn
- Streamlit

## ⚠️ Disclaimer
Predictions are trend‑based and indicative.  
They should be used alongside local agronomic expertise.
